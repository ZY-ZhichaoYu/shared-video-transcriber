# 第一次使用视频收件箱

先准备 64 位 Python（推荐 3.12）。下载仓库 ZIP 后必须完整解压，不要在 ZIP 预览窗口里运行。
不要把别人电脑的 .venv 一起复制过来；启动器会在你的电脑上创建独立环境。

Windows 双击 run_web.bat；macOS/Linux 在解压目录执行 bash run_web.sh。
首次窗口会依次显示创建环境、安装依赖、安装 Chromium。保持网络可用，不需要管理员权限。
首次选用某个语音档位时还会下载模型；“加载语音模型”不是已开始识别。
网页地址会显示在窗口中，通常为 http://127.0.0.1:7860，端口被占用时自动选择后续端口。

## 日常怎么选

朋友发口播视频：粘贴整段分享文字 → 只读文字 → 开始处理。
教程、图表或风景：选择文字 + 画面。截图是抽样，不保证捕捉每张幻灯片或瞬间动作。
自己的会议录屏：切换电脑里的视频，选择文件或粘贴完整路径。
本地原文件不会被复制或上传，清理也不会删除它；移动原文件后需重新选择才能回看。
已有 Zoom summary 可以从可选项载入 TXT，它作为参考而非逐字稿保存。

默认“细致”适合日常使用。“精细”通常更慢，仍可能听错。遇到重要专名，点核对 / 修正复听；
不要把“需复核”数量当作错误率。保留作者的梗，不要把陌生词硬改成熟悉词。

## 交给其他 AI

点击复制给 AI；长内容会打开分段窗口，按顺序粘贴，最后一段会提示开始分析。
需要画面时另行复制拼图，或下载拼图上传；复制文字不会自动附带图片。
内置 AI 摘要完全可选。不配置也能转录、复听、复制和导出。
需要时按 .env.example 创建 .env，填写你选择的服务，再重启应用；提交摘要前仍会确认发送范围。
复制到其他 AI 或主动调用摘要服务后，资料会离开本应用，需遵守该服务的隐私与费用规则。

## 出问题先看这里

| 现象 | 可以做什么 |
|---|---|
| 提示没有 Python，或跳进 Microsoft Store | 安装 python.org 的 64 位 Python 3.12，勾选 PATH，重新打开启动器 |
| 依赖下载失败 | 查看启动窗口和 .setup-logs；检查网络与代理后再次启动，不要反复删 .data |
| 已有 .venv 损坏或 Python 版本不兼容 | 先关闭服务，把 .venv 改名备份，再启动重建；保留 .data |
| Chromium 安装失败 | 网络恢复后重试；仅本地文件可用 python bootstrap.py --skip-browser |
| Linux Chromium 缺少系统库 | 按 Playwright 错误提示安装系统依赖；此操作可能需要管理员权限 |
| 提示找不到 ffmpeg | Windows 可执行 winget install Gyan.FFmpeg，完成后重新打开启动窗口 |
| 模型下载很久 / 失败 | 首次需要下载模型；检查到模型托管服务的网络。不要关闭 HTTPS 证书校验 |
| B 站 / 抖音失败 | 先确认链接可公开播放；风控、登录、会员或地区限制可能阻止获取，不能保证所有链接 |
| 原视频能转录但浏览器不能播放 | 浏览器可能不支持该编码；原文件不转码，文字和截图仍可使用 |
| 网页找不到 / 连接中断 | 保持启动窗口运行；看实际打印的端口，不要只记住 7860 |

Windows 双击 check_environment.bat，或网页“设置 → 检查运行环境”，可以查看脱敏检查结果。
macOS/Linux 可执行 bash run_web.sh --check。检查不会联网，也不会测试付费 AI 的连通性。
提 issue 时可附脱敏检查结果和必要的错误段落；日志也可能含来源链接，分享前自行核对。
不要附 .env、API key、整份私人录屏或会议逐字稿。

## 清理与升级

空间管理先预览再确认。可以保留文字、截图，只删除应用音视频缓存。
删除缓存不可在应用内撤销，来源失效时可能无法重新下载；本地原文件始终不在清理范围内。

升级前先等任务完成并关闭服务，备份 .data 和可选 .env。
Git 用户确认自己没有需要保留的代码改动后再 git pull；不要使用强制重置覆盖本地修改。
ZIP 用户解压到新文件夹，再复制自己的 .data 和 .env；不要复制旧 .venv，让新启动器重建。
如新版启动失败，先保留失败现场和新目录，再回到旧版本及对应备份；不要让两个实例同时写同一份数据。
